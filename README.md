# hugolify-theme-services-persons

## Install

Edit `config/_default/module.yaml` to install the `hugolify-theme-services-persons` module:

### V2

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-services-persons/v2
  - path: github.com/hugolify/hugolify-theme-services/v2 # required
  - path: github.com/hugolify/hugolify-theme-persons/v2 # required
  - path: github.com/hugolify/hugolify-theme/v2 # required
```

### V1

```yml
imports:
  - path: github.com/hugolify/hugolify-theme-services-persons
  - path: github.com/hugolify/hugolify-theme-services # required
  - path: github.com/hugolify/hugolify-theme-persons # required
  - path: github.com/hugolify/hugolify-theme # required
```
